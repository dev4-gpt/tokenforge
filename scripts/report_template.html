TokenForge

Six agents on Luminal rewrite the hottest function of a small LLM that runs on this laptop. A harness they cannot change keeps a kernel only if the generated text matches the baseline on tested prompts, then times it. MongoDB Atlas stores every attempt so the next round can learn from it.

Six agents, in parallel

DeepSeek-V4.1-Flash on Luminal. Three run with thinking off ("fast"), three with low reasoning ("reasoner"). Each gets a different strategy hint plus memories retrieved from Atlas.

2 · TEST

A referee they can't touch

Same clang -O3 flags, source restrictions checked, network denied. Generated text must match on tested greedy-decoding prompts. Then a warm-up and the median of 5 timed runs.

3 · LEARN

Memory in MongoDB Atlas

Every attempt is stored with an on-device embedding. A new champion must beat the old one by 5% on the 15M model and also win on the 42M model.
